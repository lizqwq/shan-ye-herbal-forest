山川不言，

一段放慢脚步的旅程，一次与草木重逢的邀请。

01 / 缘起

给忙碌生活，留一片山林。

我们习惯了匆匆走过，却很少低头看见路边的一株草。山野来信邀请你成为现代采药人，沿着蜿蜒的小径，认识那些一直生长在我们身边的植物。

在这里，没有倒计时。你可以前行，可以停步，也可以将一株草木托在掌心，读懂它的名字、形态与传统本草故事。

02 / 相逢

用双手，建立一份自己的草木档案。

在秘境漫游中，单手微微虚握前伸，沿林间小路向前。遇到草药时，先张开手掌，再握拳拾取。保持握拳向下移动，便能收入行囊，切换页面时再存入个人档案仓库。

你在同一浏览器中采集的新记录会被保留。图鉴既记载已经相逢的草木，也收藏那些等待未来探索的线索。

03 / 守护

认识自然，也尊重自然。

现实中的植物可能有相似外形或毒性。请勿仅凭图鉴辨认后自行采食、制药或外敷；不随意采摘珍稀植物，不打扰它们原本的生境。

草药文字用于传统本草文化科普，不能替代专业诊断、治疗或用药建议。

04 / 隐私

你的双手，只与此刻的山林对话。
