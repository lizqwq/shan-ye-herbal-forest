# 山野来信

GitHub Pages 公开展示版本。完整前端、图片、MediaPipe 模型和地球模型位于 docs。

在 GitHub 仓库 Settings → Pages 中将 Source 设为 GitHub Actions，推送 main 后自动发布。也可选择 Deploy from a branch → main → /docs，作为无需 Actions 配置的备用方案。正式网址以 GitHub Pages 显示的结果为准。

## 功能
关于山野、秘境漫游、药水制作、我的世界、个人档案；摄像头识别在本机进行，支持游客本地存档。包含最新连续握拳导航与真实采集统计修复。GitHub Pages 为静态托管，展示版不提供账号注册或云端存档接口。

## 本地查看
在 docs 目录运行本地 HTTP 服务器，通过 localhost 打开。线上使用 GitHub Pages HTTPS。

本仓库不包含开发者账号数据库、浏览器进度、授权凭证或个人截图。
